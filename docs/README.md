## The 30-second summary

You upload a **chest X-ray** (a photo of someone's lungs). The app does two things:

1. **AI part** — a "smart" computer model guesses which diseases might be in the X-ray
   (like pneumonia, fluid in the lungs, an enlarged heart).
2. **Fractal part** — special math measures how *rough and complex* the lung texture is,
   because disease changes that texture. It draws a colored heatmap showing *where* the
   texture looks abnormal.

Then it shows everything on a nice web page and can save a **PDF report**.

That's it. The "fractal dimension analysis" in your title = the fractal part. The rest of
these files just explain each piece slowly.
